# AI Knowledge Assistant

Assistente inteligente baseado em RAG (Retrieval-Augmented Generation),
Embeddings, Neo4j, MCP e LLMs.

## Tecnologias

- Node.js + TypeScript
- React + Vite
- Neo4j
- OpenAI API
- Ollama
- Docker

## Arquitetura

Usuário -> Frontend -> Backend -> RAG -> Neo4j -> LLM

## Objetivo

Projeto de portfólio desenvolvido para demonstrar fundamentos de Engenharia de IA:
LLMs, embeddings, busca semântica, RAG e integração com ferramentas.

## Execução

1. Copie `.env.example` para `.env`
2. Execute:

docker compose up -d

3. Inicie backend e frontend.
